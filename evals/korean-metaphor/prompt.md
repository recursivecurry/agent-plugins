# 배포 에이전트 안내

배포 에이전트는 서버마다 하나씩 설치되며, 관리 콘솔이 발급한 인증서로 제어 서버에 접속합니다. 제어 서버는 사내망에만 열려 있고, 배포 요청을 들어온 순서대로 대기열에 넣어 하나씩 처리합니다.

- 사내망·VPN 에 있는 서버만 제어 서버에 닿습니다.
- 배포 요청이 한꺼번에 오면 줄 세워 하나씩 돌립니다.
- 유휴 상태가 길어지면 제어 서버가 에이전트 세션을 정리합니다. 배포를 시작할 때 따로 깨울 필요가 없습니다.
- 대기 중인 작업은 `deploy status` 로 확인합니다.
